# MILAS BRAWL — Telegram online game

Это рабочая стартовая архитектура онлайн-игры для Telegram:
- Telegram-бот запускает Mini App
- Express отдаёт игру
- Socket.IO держит онлайн-соединения
- SQLite хранит игроков, кубки, монеты и друзей
- есть базовый матчмейкинг 1v1 и синхронизация состояния

## Запуск
1. Установить Node.js 18+.
2. Скопировать `.env.example` в `.env`.
3. Вставить токен бота и HTTPS-адрес Mini App.
4. `npm install`
5. `npm run build`
6. `npm run server`
7. В отдельном процессе `npm run bot`

Для Telegram Mini App нужен HTTPS-домен. В BotFather настройте кнопку Web App на адрес игры.

## Что уже есть
Профиль, монеты, кубки, друзья, онлайн-статусы, WebSocket-подключение, очередь PvP, бой на одной арене и сохранение результата.

## Что нужно для большой версии
3v3, полноценная физика, авторизация Telegram initData с серверной проверкой, Redis для масштабирования, PostgreSQL, античит, CDN ассетов и отдельный production-сервер.
